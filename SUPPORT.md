# Support

ATOM Hospital is an educational prototype maintained on a best-effort basis.

Before asking for help, read the [installation guide](docs/installation.md), [troubleshooting guide](docs/troubleshooting.md), and [FAQ](docs/faq.md). Sanitize all logs and never share patient data, credentials, SQLite files, or uploaded documents.

Use GitHub issues for reproducible non-security bugs. Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities or privacy incidents.
