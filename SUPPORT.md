## Include in a support request

- Commit SHA.
- PHP version and enabled extensions.
- Web server and operating system.
- Exact sanitized error message.
- Endpoint and action name, excluding personal data.
- Minimal synthetic reproduction.
- Expected and actual behavior.

## Never include

Patient-identifiable information, medical records, live database files, passwords, session cookies, access tokens, private keys, or confidential server details.

## Where to report

Use GitHub Issues for reproducible defects and documentation improvements. Use private GitHub Security Advisories for vulnerabilities.

## Scope

This repository is a local prototype. It has no hosted service, production support desk, or clinical support operation.
