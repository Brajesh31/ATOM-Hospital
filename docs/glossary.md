# 📖 Glossary

| Term | Meaning in this repository |
|---|---|
| Admin | Account role used for administrative pages and user management |
| Doctor | Role for patient assignment and clinical workflow |
| Doctor assistant | Assistant role associated with a doctor |
| Nurse | Role for patient and laboratory workflow views |
| Receptionist | Role for patient registration and front-desk workflows |
| Laboratory | Role for test orders and result upload workflows |
| Bridge endpoint | PHP script called by browser JavaScript |
| SQLite | Embedded relational database used by the project |
| Active patient | Patient record held in clinic.db |
| Archive | Historical record stored in archive.db |
| Medical record path | Current file/directory path value used by medical UI |
| CSRF | Cross-site request forgery, an attack against state-changing requests |
| XSS | Cross-site scripting, injection of executable browser content |
| Session fixation | Attack where an attacker causes a victim to use a known session identifier |
| Least privilege | Granting only the minimum required permissions |
| Synthetic data | Artificial test data that does not identify a real person |
