# 🤝 Code of Conduct

## Commitment

ATOM Hospital contributors should be able to collaborate in a respectful, safe, and technically constructive environment.

## Expected behavior

- Be respectful and assume good faith.
- Critique code and design, not people.
- Explain technical disagreement with evidence.
- Welcome beginner questions.
- Respect privacy, confidentiality, and intellectual property.
- Avoid sharing patient or staff information.
- Give actionable, inclusive feedback.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, unwanted contact, publishing private information, credential disclosure, deliberate disruption, and retaliation against good-faith reports are not acceptable.

## Reporting

Contact the maintainer privately through GitHub for conduct concerns. For security vulnerabilities, use the private process in SECURITY.md.

## Enforcement

Maintainers may remove harmful content, close discussions, restrict participation, or take proportionate action. Repeated or serious violations may result in removal from project spaces.

## Scope

This policy applies to repository issues, pull requests, reviews, discussions, and project-related communication.
